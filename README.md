 PipeBot FPV – Pipe Inspection Robot

 Overview
PipeBot FPV is a low-cost pipe inspection robot designed to travel inside narrow pipelines (4–10 inch) and provide real-time video using an FPV system.

Problem
Inspecting drainage and pipelines is difficult due to:
- Small size
- Dirty environments
- Expensive solutions

Solution
A compact FPV-controlled robot using a 3-wheel pressure mechanism.

 Mechanism
- 2 motor-driven wheels
- 1 spring-loaded top wheel
- Differential drive

 Features
- Live FPV video
- Remote control
- Works in wet pipes

 Demo Plan
Testing inside PVC pipe with water + mud.

 Components
- ESP8266 / Arduino
- Motor driver
- Gear motors
- FPV camera + transmitter

 Why FPV Needed
Used for real-time navigation inside pipes.

 Limitations
Not for fully submerged pipes.but it can travel both water and land
